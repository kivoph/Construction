CONSTRUCTION COST CONTROL

This is a standalone web app. No installation or internet connection is required to open it.

HOW TO USE
1. Extract the ZIP file.
2. Open the Construction_Cost_Control folder.
3. Open index.html in a modern web browser (Chrome recommended).

IMPORTANT
- App data is stored in the browser's local storage on the device/browser where it is used.
- Use the app's own backup/export features (if available) to keep a separate copy of your data.
- Clearing browser data may erase locally stored app data.
